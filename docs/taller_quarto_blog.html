¿Qué es Quarto?

Quarto es un sistema de publicación de código abierto. Para crear contenido, combina:

  • Texto en Markdown
  • Bloques de código en R
  • Gráficos, tablas, resultados interactivos
  • HTML y CSS, como todo en la web

Un documento Quarto .qmd puede pasar a ser un PDF, Word, HTML, parte de un sitio web, publicación en un blog, un capítulo de un libro, diapositivas (como ésta!)

Quarto → cualquier formato!

Crear el blog

En RStudio:

File → New Project → New Directory → Quarto Blog


Previsualizar

Para previsualizar el sitio, le damos Render, o ejecutamos:

Terminal

quarto preview

R

quarto::quarto_preview()

Construir el sitio

Para construir el sitio:

Terminal

quarto render

R

quarto::quarto_render()

Esto hace que Quarto renderice todos los archivos para generar el sitio HTML en la carpeta _site (por defecto, después la cambiaremos a docs)

Elementos de un blog Quarto

  • _quarto.yml: archivo de configuración general
  • index.qmd: página principal del sitio1
  • about.qmd: página de “sobre ti”
  • {x}.qmd: otras páginas para nuestro sitio web
  • posts/: carpeta con las publicaciones del blog
  • custom.scss: hoja de estilos para personalizar el blog

  1. en un blog, la página principal es usualmente la lista de publicaciones, pero puede ser una distinta

Estructura de un blog en Quarto

mi-blog/
├── _quarto.yml        # configuración
├── index.qmd          # página principal
├── about.qmd          # sobre ti
└── posts/
    ├── primer-post/
    │   └── index.qmd  # contenido
    └── segundo-post/
        └── index.qmd  # contenido

Cada documento .qmd es una página del sitio. Cada documento .qmd dentro de posts es una publicación del blog.

Publicaciones

Crea un documento index.qmd en una carpeta dentro de posts, o ejecutamos quarto::new_blog_post("Título")

Luego rellena el encabezado yaml de la publicación:

---
title: "Mi primer análisis en R"
subtitle: "Serie de análisis de datos"
author: "Tu nombre"
date: "2026-07-29"
categories: [R, análisis, datos]
image: "imagen.jpeg"
---

El contenido se escribe en Markdown, en HTML, y en bloques de código R.

Markdown

Markdown es una sintaxis de marcado simple para dar estilo a textos a partir de texto plano. Se agregan símbolos en el texto, y al renderizarlo, se convertirá en texto HTML enriquecido.

## Subtítulos
### Subsubtítulos
**negrita**
*itálica* o _itálica_
<u>subrayado</u>
~~tachado~~
`código`
[Enlaces](http://www.enlace.cl)
Agregar una nota al pie[^1].

Personalización avanzada

¿Qué es Git?


Git te permite llevar un registro de versiones y un control de cambios en tu código.

GitHub sirve para subir repositorios a un servicio online, en el cual puedes compartir tu código con otras personas, descargar el código de otros, y colaborar.

Configurar Git

install.packages("usethis")

Configurar cuenta y crear un token

usethis::use_git_config(user.name = "bastianolea", user.email = "bastianolea@gmail.com")
usethis::create_github_token()

Copiar token e ingresarlo:

gitcreds::gitcreds_set()

Confirmar situación:

usethis::git_sitrep()

Crear un repositorio local

Crear repositorio local:

usethis::use_git()

Crear un repositorio remoto

Crear repositorio remoto

Subir a GitHub Pages

Para que el repositorio se publique en la web con una dirección github.io, debemos configurarlo:

Configurar GitHub Pages

  1. En el repositorio de GitHub con tu sitio: Settings → Pages
  2. Selecciona la rama y carpeta docs
  3. Esperar a que se suba! 🤞🏼
  4. Edita la barra lateral del repo para poner el enlace

Cada vez que subas un commit al repositorio, el sitio se actualizará solito después de unos minutos!
